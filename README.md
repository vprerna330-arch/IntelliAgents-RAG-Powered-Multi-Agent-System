# IntelliAgents: RAG-Powered Multi-Agent Research System

An autonomous, multi-agent research assistant that conducts deep web research, aggregates real-time information using RAG (Retrieval-Augmented Generation), and synthesizes structured reports using LangChain, OpenAI, and Serper API.

---

## 🌟 Features

* **Autonomous Multi-Agent Architecture:** Leverages specialized agents for web search, document scraping, information extraction, and research report synthesis.
* **Real-time Web Grounding:** Integrates Serper API to retrieve live Search Engine Results Pages (SERP) for accurate, up-to-date analysis.
* **Interactive Web Dashboard:** Built with Streamlit to provide an intuitive interface for querying topics, tracking agent execution, and reviewing final outputs.
* **Secure Environment Management:** Fully isolated credential handling via environment variables (`.env`).

---

## 🛠️ Tech Stack

* **Language:** Python 3.10+
* **Frameworks & Libraries:** LangChain, LangGraph, Streamlit
* **LLM Provider:** OpenAI API (GPT-4 / GPT-3.5-turbo)
* **Search Engine Integration:** Serper API
* **Environment & Package Management:** `python-dotenv`, `pip`
